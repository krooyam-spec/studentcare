=== คำแนะนำสำหรับการติดตั้งระดับโรงเรียน (PHP & MySQL Server) ===

หากท่านดาวน์โหลดแบบ ZIP โครงการนี้ไปติดตั้งที่เซิร์ฟเวอร์โรงเรียน (เช่น XAMPP, AppServ หรือ Web Hosting)
ท่านอาจพบปัญหา "หน้าจอสีขาวว่างเปล่า" หากท่านนำทุกไฟล์รวมถึงโฟลเดอร์เช่น src/ หรือ index.html ไปวางทับหน้าเว็บหลัก

สาเหตุ:
- ไฟล์ index.html, package.json, ตระกูล src/ เป็นโค้ดสำหรับรันตัวอย่างพรีวิวด้วย React & Vite บนระบบคลาวด์ของ AI Studio เท่านั้น! เบราว์เซอร์ปกติบนเซิร์ฟเวอร์ PHP จะไม่สามารถอ่านโค้ด TypeScript (.tsx) โดยตรงได้ จึงเป็นรหัสว่างส่งผลให้แสดงผลหน้าขาว

=========================================
★★ วิธีติดตั้งและไฟล์ที่ต้องใช้จริงเท่านั้น ★★
=========================================

ให้คัดลอกเฉพาะโฟลเดอร์ "php-mysql-export" หรือ ย้ายไฟล์ 3 ไฟล์ต่อไปนี้ที่อยู่ด้านใน ไปวางที่โฟลเดอร์หลักบนเซิร์ฟเวอร์จริง (เช่น htdocs/ หรือ public_html/) ของท่าน:

๑. index.php      - ไฟล์หน้ากากการแสดงผลหลัก และฟอร์มเยี่ยมบ้านแบบทัชสกรีน 5 ฝ่าย
๒. db_connect.php - ไฟล์กำหนดค่าเชื่อมต่อฐานข้อมูล PHP PDO และระบบสร้างฐานข้อมูลอัตโนมัติ (Auto-Installer)
๓. database.sql   - สคริปต์สแกนตาราง SQL ดั้งเดิม (หากระบบไม่ติดตั้งให้อัตโนมัติ สามารถใช้ Import ผ่าน phpMyAdmin ได้)

=========================================
★★ ขั้นตอนการลบไฟล์ส่วนเกินบนเซิร์ฟเวอร์ของท่าน ★★
=========================================

หากท่านทำการวางทับทุกไฟล์ไปแล้วใน htdocs/ ให้ทำตามนี้เพื่อแก้ปัญหาหน้าจอขาวทันที:
1. เข้าไปที่โฟลเดอร์หลักผ่านหน้าจอจัดการไฟล์ (File Manager) หรือ FTP
2. ทำการ ลบ ไฟล์และโฟลเดอร์เหล่านี้ทิ้งทันที:
   - index.html (ตัวการที่ทำให้เกิดหน้าสปีดขาว!)
   - vite.config.ts
   - tsconfig.json
   - server.ts
   - package.json
   - package-lock.json
   - .env.example
   - โฟลเดอร์ src/ ทั้งหมด
   - โฟลเดอร์ assets/ ทั้งหมด
3. ตรวจสอบให้มั่นใจว่าไฟล์ที่เปิดคือ index.php
4. ทดลองเข้าเว็บโรงเรียนของท่านใหม่อีกครั้ง ระบบจะทำงานอย่างสมบูรณ์แบบครับเสถียร 100%!
